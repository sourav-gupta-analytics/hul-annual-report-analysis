# Analysis plan and acceptance criteria

Status: planned; no verified financial results yet.

## Workbook deliverables
- Source register: financial year, reporting basis, annual report URL and page, statement/note, currency and scale.
- Raw data: preserve reported amounts without overwriting them.
- Cleaned data: standardize units, distinguish missing values from zero, document transformations.
- KPI calculations: include formulas, definitions, comparable denominators and reconciliations.
- Checks: reconcile revenue and profit totals to reports; document segment eliminations and any rounding differences.

## Power BI dashboard specification
- Executive overview: revenue, operating margin, net profit margin and growth; multi-year trends.
- Segment performance: external revenue, share, growth and disclosed segment results.
- Cost analysis: expense composition and ratio trends; note material classification changes.
- Source and methodology page: reporting basis, years, definitions, assumptions and limitations.

## Publication checklist
- [ ] Select and cite comparable financial years and official reports.
- [ ] Publish the workbook, with source references and formula checks.
- [ ] Publish the PBIX where redistribution is permitted, plus dashboard screenshots or PDF.
- [ ] Reconcile dashboard measures with workbook values.
- [ ] Write three evidence-backed insights and associated management recommendations.
- [ ] Explain limitations and reproduce the workflow.
- [ ] Confirm no confidential data or third-party materials are redistributed without permission.

Update the project status in both the repository README and GitHub profile only after these checks pass.
